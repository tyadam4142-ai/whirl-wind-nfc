GITHUB PAGES:
1. Create/open your GitHub repository.
2. Upload ALL four website files directly into the repository root.
3. Make sure index.html is NOT inside another folder.
4. Open Settings → Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select your main branch and "/ (root)", then Save.
7. Wait for GitHub Pages to publish.
8. Open the generated https://...github.io/... address and test every button.

NFC:
After the GitHub Pages URL works, copy the COMPLETE URL (including https://).
Open NFC Tools → Write → Add a record → URL/URI.
Paste the GitHub Pages URL → Write.
Tap the NFC card/Sticker with a phone to test.
